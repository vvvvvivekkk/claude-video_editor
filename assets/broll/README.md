# B-roll library

Drop clips, memes, screenshots and screen recordings here. **The filename is the description** — the `broll-curator` agent matches spoken words to filenames.

Good names: `venkatesh-lakshmi-mistake.mp4`, `yc-logo.png`, `vscode-terminal-ffmpeg.mp4`, `claude-code-typing.mp4`, `money-counting.mp4`.

Optional `library.json` for richer matching:
```json
{ "venkatesh-lakshmi-mistake.mp4": { "tags": ["mistake", "oops", "telugu meme"], "best_moment": 1.5, "notes": "reaction face at 1.5s" } }
```
Formats: mp4/mov/webm, png/jpg/webp. Short clips (2–6s) work best. Only use footage you have the right to use.
