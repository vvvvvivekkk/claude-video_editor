# Briefs

One file per video: `briefs/<input-file-name>.md`. It's how you tell the editor team what the transcript can't — the point of the video, the hook, which lines must stay, which memes go where, how names are spelled.

Start from `_TEMPLATE.md`, or run `/brief input/<file>` in Claude Code and it fills it in with you (and guesses from the transcript where it can).

Standing preferences that apply to EVERY video live in `channel/CHANNEL.md` — don't repeat them here. A brief overrides the channel file when they disagree.
